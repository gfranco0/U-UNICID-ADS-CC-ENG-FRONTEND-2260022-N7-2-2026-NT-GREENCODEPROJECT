# CicloBairro — projeto Front-End

Protótipo acadêmico em HTML5, CSS3 e JavaScript sobre educação ambiental, reciclagem e valorização de cooperativas de catadores.

> **Transparência:** CicloBairro é fictício e foi criado para a atividade acadêmica. Não representa uma ONG, cooperativa ou serviço real. Não recebe doações e não coleta materiais.

## Como executar
1. Baixe ou clone este repositório.
2. Abra a pasta no VS Code.
3. Inicie um servidor local (por exemplo, Live Server) ou execute `python -m http.server 8000`.
4. Acesse `http://localhost:8000`.

Abra `index.html` diretamente se preferir, mas o servidor local oferece uma experiência mais próxima da publicação.

## Páginas
`index.html`, `sobre.html`, `projetos.html`, `impacto.html`, `acessibilidade.html`, `galeria.html`, `midia.html`, `noticias.html`, `contato.html` e `orcamento_hospedagem.html`.

## Estrutura
- `css/style.css`: identidade visual e layout responsivo.
- `js/main.js`: menu mobile, controles de acessibilidade, filtro de conteúdos, validação e rascunho local.
- `img/`: marca e ilustrações SVG.
- `assets/`: mídia demonstrativa e transcrição.
- `docs/`: escopo, diário, orçamento, testes e transparência de IA.

## Funcionalidades
Menu responsivo, navegação entre dez páginas, skip link, foco visível, alto contraste, aumento de texto, filtro de conteúdos e formulário com validação JavaScript. O rascunho do formulário e as preferências são guardados no localStorage deste navegador.

**Importante:** o formulário não envia dados a um servidor. Não informe dados pessoais sensíveis. Os indicadores de impacto são metas ilustrativas, não resultados reais.

## Antes da entrega
Complete os dados da equipe; teste todas as páginas no validador Nu HTML Checker; faça testes manuais com teclado, leitor de tela e dispositivos reais; atualize o diário com decisões e dificuldades reais; registre feedback do MVP; confira a publicação HTTPS e o histórico Git com contribuições reais de cada integrante.

## Tecnologias
HTML5 semântico, CSS3 (Grid/Flexbox e media queries), JavaScript nativo e Git/GitHub.
