# Documentação — CicloBairro

Este diretório reúne os documentos de apoio da atividade.

- `escopo-projeto.md`: problema, público, objetivos, escopo, tecnologia e critérios de aceite.
- `diario-de-bordo.md`: modelo inicial a preencher durante o desenvolvimento.
- `orcamento.md`: comparativo de hospedagem e domínio.
- `evidencias_testes.md`: verificações já executadas e pendências de validação formal.
- `melhorias-mvp.md`: espaço para registrar feedback real e melhorias entre MVP e versão final.
- `uso-de-ia.md`: registro de uso de ferramentas de IA.
- `fontes-e-creditos.md`: referências, recursos e créditos.

Não invente nomes, RA, contribuições, entrevistas, feedback, métricas ou testes. Preencha os campos em aberto com dados reais da equipe.
