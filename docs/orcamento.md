|---|---|---|
| Registro.br | .br, aproximadamente R$ 40/ano | Opção simples para endereço brasileiro. |

## Recomendação
Usar GitHub Pages sem domínio próprio para o protótipo: custo inicial zero e configuração simples. Caso a equipe queira endereço próprio brasileiro, avaliar Registro.br. O site é estático e não necessita banco de dados ou servidor de aplicação para a demonstração.
