Escolha recomendada para o protótipo

GitHub Pages com domínio gratuito padrão é suficiente para a atividade e evita custo inicial. Para um endereço próprio brasileiro, considerar Registro.br, estimado em R$ 40 por ano. Não é necessário contratar serviço para executar o site localmente.
